# fnf - lumen engine ✨

a fork of p-slice engine (specifically version 2.3.1) that aims to be more modular and easier to script outside of songs.

why did i make this? i just thought p-slice was a bit too hardcoding-oriented. i also wanted scripting capabilities similar to emi3's psych fork that let you script outside of songs, plus a more modular structure so you can add features without editing the engine itself.

basically a crossover between a bunch of psych forks.

## important notice

this engine only works on windows due to how the code is structured. if you want to port it to other platforms, you'll need to rewrite parts of the file system, audio system, and input system. feel free to open a pull request if you do.

or just use wine. (i use windows so i can't test on linux or macos.)

also: lumen doesn't support mobile. either use an emulator, use p-slice's mobile builds, or rewrite the code if you want that.
